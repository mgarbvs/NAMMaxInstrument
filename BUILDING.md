# Building from source

## 1. Clone and set up thirdparty libraries

```bash
git clone https://github.com/mgarbvs/NAMMaxInstrument.git
cd NAMMaxInstrument/external_src/thirdparty

git clone https://github.com/Cycling74/max-sdk.git ../max-sdk
git clone https://github.com/sdatkinson/NeuralAmpModelerCore.git NeuralAmpModelerCore
git clone https://github.com/AlexHarker/HISSTools_Library.git HISSTools_Library

# Eigen (header-only)
git clone https://gitlab.com/libeigen/eigen.git eigen

# nlohmann/json (single header)
mkdir -p nlohmann_json
curl -L -o nlohmann_json/json.hpp \
    https://github.com/nlohmann/json/releases/latest/download/json.hpp
```

Pin `NeuralAmpModelerCore` and `HISSTools_Library` to stable commits — see `external_src/thirdparty/README.md`.

## 2. Build the native externals

```bash
ARCHS=arm64 scripts/build_external_mac.sh          # Apple Silicon
# or
ARCHS="x86_64;arm64" scripts/build_external_mac.sh # Universal
```

Produces six `.mxo` bundles in `m4l/`.

## 3. Build the Max for Live device

```bash
bash build_combined.sh
```

Or step by step:

```bash
python3 scripts/build_combined_maxpat.py m4l/NAM.maxpat
python3 scripts/validate_maxpat.py m4l/NAM.maxpat
python3 scripts/build_amxd.py m4l/NAM.maxpat m4l/NAM.amxd
```

## 4. Run tests

```bash
node tests/test_nam_loader.js
python3 tests/test_validate_maxpat.py
```

## Architecture notes

- `NAM.maxpat` is generated by `scripts/build_combined_maxpat.py` — never hand-edit it or `NAM.amxd`. Edit the build script, then rebuild.
- `.mxo` externals must be co-located with `NAM.amxd` — M4L does not search subdirectories.
- `nam_loader.js` runs in Max's JS runtime (ES5 — no arrow functions, no `const` at file scope). `nam_state.js` runs in Node-for-Max (full Node.js).
- IR convolution uses HISSTools partitioned FFT (`irconv~`) because `multiconvolve~` is absent from the M4L runtime.
- Model load in `nam~` is thread-safe via double-buffer atomic swap (worker thread constructs, audio thread hot-swaps).
