Overview

NAM Max for Live is a Max for Live audio effect that loads Neural Amp Modeler (.nam) files directly in Ableton Live. It reproduces the full signal chain of a guitar rig in software: preamp tone, noise gate, a 3-band biquad EQ, and optional cabinet IR convolution — all without any VST or AU plugin.

The device has three collapsible sections. You can show or hide the Tone Stack and IR Cabinet sections independently to reclaim screen space. The NAM Amp Head section is always visible.

Platform: macOS only (Apple Silicon and Intel universal). The .mxo externals (NAM inference, IR convolution, tone stack) are native macOS bundles. Windows is not currently supported.

Installation & first use

All files inside m4l/ must remain together in the same folder — Max for Live searches only the directory containing the .amxd for native externals.

  1. Copy every file in m4l/ to your Ableton User Library:
    ~/Music/Ableton/User Library/Presets/Audio Effects/Max Audio Effect/
  2. In Ableton Live, drag NAM.amxd onto an audio track.
  3. Click Set NAM Root and choose the folder containing your .nam files. Subfolders are scanned automatically.
  4. Use the category and file menus to select a model. The amp loads immediately.
  5. Optionally, click Set IR Root and select a .wav IR file to add cabinet simulation.

The device saves your root folders and the last selected model and IR across Live sessions — they reload automatically the next time you open the set.

Tip: You can also drag a .nam file directly onto the waveform/grill area in the NAM Amp Head section, or drag a .wav directly onto the waveform display in the IR Cabinet section, to load without using the menus.

Each stage can be bypassed independently. The gate, tone stack, and IR each have a hard bypass switch. The whole device also has a master Bypass toggle that short-circuits the entire chain with latency compensation.

NAM Amp Head section

NAM Amp Head

This section is always visible. It covers model loading, input/output levels, and the master bypass and section collapse toggles.

Loading models

NAM model files (.nam) are neural network snapshots of real amplifiers. Free models are available on Tone3000.

Set NAM Root Opens a folder picker. Point it at the root of your .nam library. All subfolders become categories in the menu below.
Trim (checkbox) When enabled, strips the common folder-name prefix from category labels so menus are easier to read.
Category menu Lists the subfolders inside your NAM Root. Use the < / > arrows to step through them.
Model menu Lists .nam files in the selected category. Use the < / > arrows to audition models one by one.
Drag & drop Drop any .nam file onto the amp grill area to load it directly, bypassing the menu system.
Status bar Shows the name of the currently loaded model, or (no model loaded) on startup. Displays error messages if a model file cannot be read.

Levels

Input (left fader) Gain before the NAM inference stage. ±36 dB. Use this to hit the model at the right drive level — NAM models are trained at a specific input level, so more input = more saturation.
NAM Out (right fader) Output level after NAM inference, before the tone stack and IR stages. ±36 dB. Use this to match levels when comparing models.

Bottom row

Bypass Hard-bypasses the entire device with latency compensation — the dry signal is delay-matched to the IR convolution latency so Ableton's PDC stays accurate.
Tone Collapses or expands the Gate + Tone Stack section. The tone stack itself stays active when collapsed.
IR Collapses or expands the IR Cabinet section. IR convolution stays active when collapsed.

Gate + Tone Stack section

Gate + Tone Stack

This section can be collapsed. It contains the noise gate threshold and the 3-band biquad EQ.

NAM Dry/Wet

NAM (dial) Crossfades between the dry input signal and the NAM model output. 0% = fully dry (amp bypassed), 100% = fully processed. Default is 100%.

Noise gate

The gate uses a sidechain architecture: an envelope follower on the input signal controls a gain stage after NAM inference. This means the gate tracks picking dynamics but doesn't clip the tail of NAM's own sustain artificially.

Gate (dial) Threshold in dB. Signal below this level is muted. Range: −70 to 0 dB. Default is −70 dB (fully open — gate has no effect). Raise the threshold to silence amp hiss and string noise between notes.
Gate off / Gate on Hard-bypasses the gate entirely. When off, the signal passes through NAM unaffected regardless of the threshold setting.
Setting the threshold: Start with the gate on and the threshold at −70 dB, then raise it slowly while not playing until the amp hiss disappears. Avoid setting it too high or fast picking attacks will be cut.

Tone stack

The tone stack is the same three-band EQ used in the Neural Amp Modeler plugin (BasicNamToneStack): three independent biquad filters in series, computed with standard Audio EQ Cookbook formulas. All knobs run 0–10; position 5 = flat (0 dB).

KnobFilter typeCenter freqRange
BassLow shelf150 Hz±20 dB (4 dB per step)
MidPeaking425 Hz±15 dB (3 dB per step)
TrebleHigh shelf1800 Hz±10 dB (2 dB per step)
Bass Low shelf at 150 Hz. Raises or lowers body and warmth. ±20 dB range — the widest of the three bands.
Mid Peaking filter at 425 Hz. The Q is narrower when boosting (0.7) and wider when cutting (1.5), so boosts feel focused and cuts feel smooth. ±15 dB.
Treble High shelf at 1800 Hz. Controls brightness and pick attack. ±10 dB.

The EQ curve display shows the exact combined frequency response of the current settings in real time — it uses the same biquad math as the DSP, not a stylized approximation.

Tone off / Tone on Hard-bypasses the tone stack. The EQ curve display goes inactive when the tone stack is off.
Classic settings:
  • Flat: Bass 5, Mid 5, Treble 5
  • Scooped (metal / modern): Bass 7, Mid 2, Treble 7
  • Presence boost: Bass 4, Mid 5, Treble 8
  • Warm jazz/blues: Bass 6, Mid 6, Treble 3

IR Cabinet section

IR Cabinet

This section can be collapsed. It loads a cabinet impulse response (.wav) and convolves it with the signal using a partitioned FFT algorithm. The IR simulates the acoustic character of a speaker cabinet and microphone placement.

Loading IRs

Set IR Root Opens a folder picker. Point it at your IR library. Subfolders become categories.
Trim (checkbox) Strips common prefix from category/file names, same as in the NAM section.
Category menu Subfolder categories inside your IR Root. Navigate with < / >.
File menu Individual IR files in the selected category. Navigate with < / >.
Duration display Shows the length of the loaded IR file in seconds (e.g., 0.18 sec). Longer IRs capture more room detail but require more CPU.
Waveform display Shows the waveform of the loaded IR. Longer IRs with prominent early reflections typically produce more "air" and room character.
Drag & drop Drop any .wav file onto the waveform display to load it directly.

IR blend and bypass

IR (dial) Crossfades between the dry (pre-IR) signal and the convolved output. 0% = cabinet bypassed, 100% = full IR. The dry path is delay-compensated to match IR latency, so blending stays in phase.
IR off / IR on Hard-bypasses IR convolution entirely. Use this to compare the amp tone with and without cabinet coloration.
Latency: IR convolution adds processing latency proportional to the IR length. The device automatically reports this latency to Live's PDC engine, so other tracks stay in sync. The Bypass toggle in the NAM section also compensates for this delay when hard-bypassing the whole device.
IR level normalization: The device applies a −18 dB normalization factor to the IR output to match the level convention used by the Neural Amp Modeler plugin. This is calculated per sample rate. You don't need to adjust for it manually.

Workflow tips

Typical starting point

  1. Set NAM Root → pick a model. Listen to the raw amp tone (IR off, Tone off, Gate off).
  2. Adjust Input gain to get the drive character you want. More input = more saturation.
  3. Enable the Tone Stack and dial in Bass/Mid/Treble to taste.
  4. Enable the IR and pick a cabinet that fits the amp style. A Fender model pairs well with a 1×12 or 2×12 IR; a high-gain model typically works well with a 4×12.
  5. Raise the gate threshold until hiss between notes disappears, then back off slightly.
  6. Use NAM Out to match volume against other tracks or presets.

Ableton automation

All dials and toggles are Live-mapped parameters and can be automated or modulated in Live. The Tone Stack dials (Bass, Mid, Treble) respond to MIDI mapping and automation envelopes. Map them to a MIDI controller to do real-time tone shaping during a session.

Comparing models quickly

Use the < / > arrows next to the Model menu to step through .nam files in the current category while playback is running. The new model loads mid-stream with no click.

Collapsing sections

Click Tone or IR in the bottom row of the NAM section to collapse those panels. The device shrinks to save space. The signal processing continues running — collapsing is display-only.
